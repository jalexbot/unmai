# உண்மை · Unmai

**A non-partisan fact reference for Tamil Nadu politics.**

Every claim is sourced. No spin. No opinion without evidence.
Built to counter misinformation from all parties — DMK, TVK, AIADMK, BJP, and others.

🌐 **Live site:** https://jalexbot.github.io/unmai-tn

---

## Modules

| Module | Description |
|---|---|
| Said vs Did | What leaders said vs what actually happened |
| Promise Tracker | Manifesto promises tracked against delivery |
| Myth vs Fact | Viral claims checked against data |
| Scheme Hub | Welfare schemes — before, after, current status |
| Data & Stats | TN indicators from official + independent sources |

## Contributing

All content lives in `content/en/` and `content/ta/` as Markdown files.

To add or correct an entry:
1. Fork this repo
2. Edit or add a `.md` file in the relevant module folder
3. Every entry must include at least one source with a URL
4. Submit a pull request with a note on what you changed and why

## Principles

- No claim without a source
- No opinion — only evidence-based conclusions
- All parties held to the same standard
- Disputed facts shown as disputed, with both sides cited
- Every entry shows when it was last updated
